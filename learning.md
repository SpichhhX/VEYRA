# VEYRA Journal

## 1. Publish a working website

My first task is to publish these pages with GitHub Pages and make sure the navigation works on my phone.

## 2. Make every page useful

I will replace starter text with my own notes, examples, and things I have actually tried. Each page should answer one clear question.

## 3. Connect Search Console

Once my site is public, I will verify its URL in Google Search Console, submit the sitemap, and inspect my homepage.

## 4. Record an experiment

For each change, I will write down what I changed, why I changed it, and what I observed later. Search results take time, and indexing is not guaranteed.
